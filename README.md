## 💡 FamCare là gì?

**FamCare** là một ứng dụng web (chạy ngay trên trình duyệt – Chrome, Safari, Edge…) giúp **các gia đình Việt** chăm sóc sức khoẻ người thân, đặc biệt là **người lớn tuổi**:

- Không còn lo **đọc nhầm toa thuốc bác sĩ viết tay**
- Không còn quên **liều thuốc hằng ngày**
- Biết **nên ăn gì – kiêng gì** theo bệnh lý
- Lưu lại **toàn bộ hồ sơ sức khoẻ** của các thành viên trong gia đình

👉 **Bạn không cần biết về công nghệ – chỉ cần có điện thoại hoặc máy tính có internet.**

## 🌐 Dùng thử online (KHÔNG cần cài đặt)

> ⭐ **Đây là cách dễ nhất – khuyên dùng cho mọi người không phải dân code.**

### Bước 1: Mở trình duyệt
Dùng **Chrome**, **Safari**, **Edge** hoặc **Cốc Cốc** trên điện thoại / máy tính.

### Bước 2: Truy cập đường link
👉 **https://id-preview--33fcea1c-27b2-453c-a889-18cec38072ff.lovable.app**

*(Sau khi dự án publish, link chính thức sẽ là `famcare.lovable.app` hoặc tên miền riêng – sẽ cập nhật ở đây.)*

### Bước 3: Đăng ký tài khoản
1. Bấm nút **"Đăng ký"** ở góc phải
2. Điền **Email** và **mật khẩu** (mật khẩu ít nhất 6 ký tự)
3. Bấm **"Tạo tài khoản"** → vào thẳng app, không cần xác minh email

### Bước 4: Bắt đầu sử dụng 🎉
Đăng nhập xong là dùng được toàn bộ tính năng – xem hướng dẫn chi tiết bên dưới.

## 📚 Hướng dẫn sử dụng từng tính năng

### 📷 1. Quét toa thuốc bằng AI

1. Vào menu **Scanner** (biểu tượng máy ảnh)
2. Bấm **"Tải ảnh lên"** → chọn ảnh toa thuốc (chụp sẵn từ điện thoại)
3. Đọc và đồng ý **Điều khoản AI**
4. Đợi 5-10 giây → AI sẽ trả về:
   - Tên thuốc
   - Liều lượng
   - Cách dùng
   - Chẩn đoán (nếu có)
5. Bấm **"Lưu vào tủ thuốc"** để lưu lại

💡 *Mẹo: Chụp ảnh đủ sáng, không bị mờ, toa nằm thẳng → kết quả chính xác hơn.*

### 💊 2. Tủ thuốc gia đình (Cabinet)

- Xem tất cả thuốc đã lưu
- Bấm **"+ Thêm thuốc"** để nhập thủ công
- Bật **"Chia sẻ"** nếu muốn người thân khác trong gia đình thấy thuốc này
- Bấm vào thuốc để **sửa / xoá**

### 🍲 3. Lập thực đơn AI (Meal Plan)

1. Vào menu **Meal Plan**
2. Bấm **"Tạo thực đơn mới"**
3. AI sẽ dựa trên thuốc và bệnh lý của bạn để gợi ý:
   - Bữa sáng / trưa / tối
   - Món nên ăn
   - Món cần kiêng
4. Lọc theo tab **Sáng / Trưa / Tối** để xem nhanh

### 👨‍👩‍👧 4. Quản lý gia đình

- Vào **Hồ sơ (Profile)** → tab **"Thành viên gia đình"**
- Bấm **"+ Thêm người thân"** → nhập email tài khoản FamCare của họ
- Sau khi liên kết, bạn có thể **xem chung tủ thuốc** với họ

### ⚙️ 5. Cài đặt

- **Đổi mật khẩu**
- **Bật/tắt giao diện tối** (chế độ ban đêm)
- **Bật/tắt thông báo nhắc thuốc**

## 💻 Cài đặt & chạy trên máy tính (cho dev)

> ⚠️ Phần này chỉ dành cho **lập trình viên** muốn chạy mã nguồn local.
> Người dùng bình thường **bỏ qua phần này**, chỉ cần dùng link online ở trên.

### Yêu cầu

- **Node.js** ≥ 18 ([tải tại đây](https://nodejs.org))
- **PostgreSQL** (hoặc dùng [Supabase](https://supabase.com) / [Neon](https://neon.tech) miễn phí)
- **Gemini API key** ([lấy miễn phí tại đây](https://aistudio.google.com/apikey))

### Bước 1: Clone mã nguồn

```bash
git clone <repo-url>
cd famcare
```

### Bước 2: Cài thư viện

```bash
npm install
```

### Bước 3: Tạo file `.env` ở thư mục gốc

```env
DATABASE_URL="postgresql://user:pass@host:5432/dbname"
JWT_SECRET="chuoi_bi_mat_bat_ky"
GEMINI_API_KEY="AIza..."
ENCRYPTION_KEY="chuoi_dai_dung_32_ky_tu_nhe_nhang"
ALLOWED_ORIGINS="http://localhost:8080"
```

### Bước 4: Khởi tạo database

```bash
npx prisma generate
npx prisma db push
```

### Bước 5: Chạy app

Mở **2 cửa sổ terminal**:

**Terminal 1 – chạy backend:**
```bash
npm run server
```

**Terminal 2 – chạy frontend:**
```bash
npm run dev
```

Truy cập **http://localhost:8080** 🎉

## 🛠 Công nghệ sử dụng

- **Frontend:** React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui
- **Backend:** Node.js (Express) + Prisma ORM
- **Database:** PostgreSQL
- **AI:** Google Gemini 1.5 Flash (OCR + lập thực đơn)
- **Auth:** JWT + bcryptjs
- **Bảo mật:** Mã hoá AES-256 cho thông tin nhạy cảm
